# Paymaster API RPC Methods: EntryPoint v0.6

This page documents the Paymaster API for accounts on EntryPoint v0.6. If you are starting a new integration, use the [main Paymaster API reference](/wallet/paymaster/rpc-methods), which covers EntryPoint v0.9 and v0.8. The reference for [EntryPoint v0.7](/wallet/paymaster/rpc-methods-v07) is on its own page.

## Endpoints at a Glance

| Method | Params | Returns | Spec |
|---|---|---|---|
| [pm_getPaymasterStubData](#pm_getpaymasterstubdata) | `[userOperation: object, entrypoint: string, chainId: string, context: object]` | `{ paymasterAndData, sponsor?, isFinal }` | ERC-7677 |
| [pm_getPaymasterData](#pm_getpaymasterdata) | `[userOperation: object, entrypoint: string, chainId: string, context: object]` | `{ paymasterAndData, sponsor? }` | ERC-7677 |
| [pm_sponsorUserOperation](#pm_sponsoruseroperation) | `[userOperation: object, entrypoint: string, context: object]` | `{ paymasterAndData, callGasLimit?, verificationGasLimit?, preVerificationGas?, maxFeePerGas?, maxPriorityFeePerGas?, sponsorMetadata? }` | Candide |
| [pm_supportedERC20Tokens](#pm_supportederc20tokens) | `[entrypoint: string]` | `{ paymasterMetadata, tokens[] }` | Candide |
| [pm_supportedEntryPoints](#pm_supportedentrypoints) | `[]` | `string[]` | Candide |
| [pm_chainId](#pm_chainid) | `[]` | `string` | Candide |

## Entrypoint V0.6

### pm_getPaymasterStubData

[ERC-7677](https://eips.ethereum.org/EIPS/eip-7677) compatible method. Equivalent to Candide's [`pm_sponsorUserOperation`](#pm_sponsoruseroperation).
It always returns `isFinal: false`: call `pm_getPaymasterData` afterwards to get the final paymaster data.

Sends a UserOperation to a paymaster for off-chain verification. If approved, it will return the `paymasterAndData`. Unlike `pm_sponsorUserOperation`, it does not return gas overrides: the gas fields of the UserOperation are used as sent.

Supports two types of Gas Policies:

- **Public Gas Policies**: These are gas policies provided by third parties, which do not require a sponsorship policy ID.
- **Private Gas Policies**: These require a sponsorship policy ID and can be used if no public gas policy matches the user operation.

If the paymaster rejects the UserOperation, it returns a standard JSON-RPC error with the reason.

#### Invocation

```json
{ "method": "pm_getPaymasterStubData", "params": [userOperation: object, entrypoint: string, chainId: string, context: object] }
```

#### Return

```json
{
  "result": {
    paymasterAndData: string,
    sponsor?: {
      name: string,
      icon: string,
    },
    isFinal: boolean
  }
}
```

### pm_sponsorUserOperation

Sends a UserOperation to a paymaster for off-chain verification. If approved, it will return the `paymasterData`. It will also return gas overrides when the mode for gas sponsorship uses a Gas Policy.

- **ERC-20 Gas Payments**: No gas overrides are returned.
- **Gas Policies**: Mandatory `callGasLimit`, `verificationGasLimit`, `preVerificationGas`, `maxFeePerGas`, and `maxPriorityFeePerGas` fields are returned.

Supports two types of Gas Policies:

- **Public Gas Policies**: These are gas policies provided by third parties, which do not require a sponsorship policy ID.
- **Private Gas Policies**: These require a sponsorship policy ID and can be used if no public gas policy matches the user operation.

If the paymaster rejects the UserOperation, it returns a standard JSON-RPC error with the reason.

#### Invocation

```json
{ "method": "pm_sponsorUserOperation", "params": [userOperation: object, entrypoint: string, context: object] }
```

#### Return

```json
{
  "result": {
    paymasterAndData: string,
    callGasLimit?: string,
    verificationGasLimit?: string,
    preVerificationGas?: string,
    maxFeePerGas?: string,
    maxPriorityFeePerGas?: string,
    sponsorMetadata?: {
      name: string,
      description: string,
      url: string,
      icons: string[],
    }
  }
}
```

### pm_supportedERC20Tokens

Gets supported ERC-20 Tokens for gas payments, along side the paymaster metadata

#### Invocation

```json
{ "method": "pm_supportedERC20Tokens", "params": [entrypoint: string] }
```

#### Return

```json
{
  "result": {
    paymasterMetadata: {
      name: string,
      description: string,
      icons: string[],
      address: string,
      sponsoredEventTopic: string,
      dummyPaymasterAndData: string,
    },
    tokens: [{
      name: string,
      symbol: string,
      address: string,
      decimals: string, // hex-encoded, for example "0x12" for 18
      exchangeRate: string,
    }]
  }
}
```
