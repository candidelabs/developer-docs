# CandidePaymaster (Advanced)

`CandidePaymaster` is the client for Candide-hosted paymasters. For one-shot sponsorship and ERC-20 gas, start with the standard [`Erc7677Paymaster`](/wallet/abstractionkit/paymaster) instead. Use `CandidePaymaster` when you need the EntryPoint v0.9 two-phase `commit -> sign -> finalize` flow, which lets the user sign while the paymaster prepares its signature, or Candide's token and metadata APIs below.

### Import

```ts
import { CandidePaymaster } from "abstractionkit";
```

### How to Use

Initialize a Paymaster with your RPC URL. Get an API key from the [dashboard](https://dashboard.candide.dev).

```ts title="paymaster.ts"
import { CandidePaymaster } from "abstractionkit";

const paymasterRPC = "https://api.candide.dev/public/v3/11155111";
const paymaster: CandidePaymaster = new CandidePaymaster(paymasterRPC);
```

Then consume Paymaster methods:

```ts
const supportedEntryPoints = await paymaster.getSupportedEntrypoints();
```

## Methods

### createSponsorPaymasterUserOperation

Returns the paymaster data if the the userOperation has a Gas Policy. Otherwise it returns an error message. Supports two types of Gas Policies:

- **Public Gas Policies**: These are gas policies provided by third parties, which do not require a sponsorship policy ID.
- **Private Gas Policies**: These require a sponsorship policy ID and can be used if no public gas policy matches the user operation.

### createTokenPaymasterUserOperation

Estimates gas limits and returns the user operation with the paymaster data for ERC-20 Token sponsorship.

Some tokens like USDT do not allow changing a non-zero allowance directly. For known tokens (e.g. USDT on Ethereum mainnet), the SDK automatically prepends an `approve(0)` call before the actual approval. You can also manually trigger this behavior for other tokens by setting `resetApproval: true` in the overrides.

The `overrides` parameter also accepts an `entrypoint` field, which allows you to manually specify the EntryPoint address instead of relying on auto-detection from the UserOperation structure.

By default the prepended `approve` grants twice the quoted token cost. Set `overrides.approveAmount` (a `bigint` in the token's smallest unit) to choose the allowance yourself, for example to cap it at a maximum fee the user agreed to. The method throws a `PAYMASTER_ERROR` if the amount is below the quoted token cost, with both values in the error's `context`. The token cost is quoted during the call, so it isn't known beforehand. The `finalize` signing phase builds no approval and ignores this override.

The returned `tokenQuote` reports the paymaster the prepended `approve` was granted to (`paymaster`) and the allowance it set (`approveAmount`), so you can compare the spender against your configured paymaster without decoding `callData`. The method throws a `PAYMASTER_ERROR` if the final paymaster data is missing a paymaster or names a different one than the approval spender.

#### Usage

<Tabs>
<TabItem value="example.ts" label="example.ts">

```ts
// highlight-start

  await paymaster.createTokenPaymasterUserOperation(
    smartAccount,
    userOperation,
    erc20TokenAddress,
    bundlerRPC,
```

### calculateUserOperationErc20TokenMaxGasCost

Converts a UserOperation's maximum gas cost to the ERC-20 token at the paymaster's current exchange rate. It uses the same calculation as `tokenQuote.tokenCost`, so it leaves out Candide's post-operation overhead and markup. For the most a finished UserOperation can charge the user, use [`decodeTokenQuote`](/wallet/abstractionkit/paymaster#decodetokenquote).

#### Usage

<Tabs>
<TabItem value="example.ts" label="example.ts">

```ts
import { CandidePaymaster } from "abstractionkit";

const erc20TokenAddress = "0xFa5854FBf9964330d761961F46565AB7326e5a3b"; // CTT test token
// Use createUserOperation() to help you construct a userOp
const userOperation = await smartAccount.createUserOperation(/* ... */);

const paymasterRPC="https://api.candide.dev/public/v3/11155111";
const paymaster: CandidePaymaster = new CandidePaymaster(paymasterRPC);

// highlight-start
const cost = await paymaster.calculateUserOperationErc20TokenMaxGasCost(
  smartAccount,
  userOperation,
  erc20TokenAddress,
);
// highlight-end
```

### createPaymasterUserOperation

:::note Private on CandidePaymaster
`CandidePaymaster.createPaymasterUserOperation` is a private helper, not part of the public API. Use [`createSponsorPaymasterUserOperation`](#createsponsorpaymasteruseroperation) for gas sponsorship or [`createTokenPaymasterUserOperation`](#createtokenpaymasteruseroperation) for ERC-20 token payment instead.

`Erc7677Paymaster` exposes a public method with the same name; that one is the recommended entry point for the standard ERC-7677 flow and is documented on the [Paymaster page](/wallet/abstractionkit/paymaster#erc7677paymaster).
:::
