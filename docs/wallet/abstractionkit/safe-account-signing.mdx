# Safe Account Transactions and Signing

Every AbstractionKit Safe account class inherits these methods from the base `SafeAccount` class: [Safe Unified Account](/wallet/abstractionkit/safe-unified-account) (`SafeMultiChainSigAccountV1` and `SafeMultiChainSigAccountV2`, the recommended classes), [Safe Account V3](/wallet/abstractionkit/safe-account-v3) (`SafeAccountV0_3_0`) and [Safe Account V2](/wallet/abstractionkit/safe-account-v2) (`SafeAccountV0_2_0`). Building, estimating and signing with private keys are class-specific and documented on each class page. Owner, module and address methods are on [Safe Account Setup, Owners and Modules](/wallet/abstractionkit/safe-account-management).

The examples import `SafeMultiChainSigAccountV1 as SafeAccount`, the recommended class for new Safes. Each method is called the same way on `SafeMultiChainSigAccountV2`, `SafeAccountV0_3_0` and `SafeAccountV0_2_0`: change the import to your class. Where a class differs (UserOperation type, default addresses, example output), the section says so.

## Methods

### sendUserOperation

This method sends the UserOperation to the bundler to be executed on-chain. It returns a promise `SendUseroperationResponse` object to confirm the on-chain inclusion of the UserOperation.

<Tabs>
<TabItem value="example.ts" label="example.ts">

```ts title="example.ts"
const sendUserOperationResponse = await smartAccount.sendUserOperation(userOperation, bundlerUrl)

console.log("sendUserOperationResponse: ", sendUserOperationResponse);
console.log("UserOperation sent. Waiting to be included...");

const receipt = await sendUserOperationResponse.included()

console.log("receipt: ", receipt);
```

On `SafeAccountV0_2_0` (EntryPoint v0.6), `userOperation` is a `UserOperationV6` (see [Safe Account V2](/wallet/abstractionkit/safe-account-v2#createuseroperation) for its fields), and `entrypointAddress` in the response and `entryPoint` in the receipt are the EntryPoint v0.6 address `0x5FF137D4b0FDCD49DcA30c7CF57E578a026d2789`. On the Safe Unified Account (`SafeMultiChainSigAccountV1` and `SafeMultiChainSigAccountV2`, EntryPoint v0.9), `userOperation` is a `UserOperationV9` (see [Safe Unified Account](/wallet/abstractionkit/safe-unified-account#createuseroperation)).

To send from a fresh instance, attach the account by its address:

```ts title="example.ts"
const account = new SafeAccount(userOperation.sender);
const response = await account.sendUserOperation(userOperation, bundlerUrl);
const receipt = await response.included();
```

### signUserOperationWithSigners

Signs a UserOperation using one or more [`ExternalSigner`s](/wallet/abstractionkit/external-signers) instead of raw private keys. Integrates viem, ethers, hardware wallets, HSMs, MPC services, and WebAuthn through the same API.

<Tabs>
<TabItem value="viem" label="viem example">

```ts title="example.ts"
import { fromViem } from "abstractionkit";
import { privateKeyToAccount } from "viem/accounts";

const viemAccount = privateKeyToAccount("0x...");

userOperation.signature = await smartAccount.signUserOperationWithSigners(
  userOperation,
  [fromViem(viemAccount)],
  chainId,
);
```

</TabItem>
<TabItem value="ethers" label="ethers example">

```ts title="example.ts"
import { fromEthersWallet } from "abstractionkit";
import { Wallet } from "ethers";

const wallet = new Wallet("0x...");

userOperation.signature = await smartAccount.signUserOperationWithSigners(
  userOperation,
  [fromEthersWallet(wallet)],
  chainId,
);
```

</TabItem>
</Tabs>

See [External Signers](/wallet/abstractionkit/external-signers) for the full list of adapters and custom-signer integrations.

On `SafeAccountV0_2_0` (EntryPoint v0.6), `userOperation` is a `UserOperationV6`. On the Safe Unified Account (`SafeMultiChainSigAccountV1` and `SafeMultiChainSigAccountV2`, EntryPoint v0.9), it is a `UserOperationV9`; the signature is always encoded with the multichain scheme (`isMultiChainSignature: true`), and a `multiChainMerkleProof` option is rejected. To sign several UserOperations under one signature, use [`signUserOperationsWithSigners`](/wallet/abstractionkit/safe-unified-account-multichain#signuseroperationswithsigners).

### formatEip712SignaturesToUseroperationSignature

A static method to format a list of eip712 signatures to a userOperation signature.

#### Usage

<Tabs>
<TabItem value="ethers" label="ethers example">

```ts
import { SafeMultiChainSigAccountV1 as SafeAccount } from "abstractionkit";
import { Wallet } from "ethers";

const ownerPrivateKey = process.env.PRIVATE_KEY as string;
const signer = new Wallet(ownerPrivateKey);
const ownerPublicAddress = signer.address;

const smartAccount = SafeAccount.initializeNewAccount([ownerPublicAddress]);

let userOperation = ... // smartAccount.createUserOperation(..)

const safeUserOpHash = SafeAccount.getUserOperationEip712Hash(userOperation, chainId);
const signature = signer.signingKey.sign(safeUserOpHash).serialized;

const formatedSig = SafeAccount.formatEip712SignaturesToUseroperationSignature(
  [ownerPublicAddress],
  [signature],
  { isMultiChainSignature: true }, // required for SafeMultiChainSigAccountV1 and V2; omit for SafeAccountV0_3_0 and V0_2_0
);
userOperation.signature = formatedSig;
```

</TabItem>
<TabItem value="viem" label="viem example">

```ts
import { SafeMultiChainSigAccountV1 as SafeAccount } from "abstractionkit";
import { privateKeyToAccount } from "viem/accounts";

const ownerPrivateKey = process.env.PRIVATE_KEY as string;
const signer = privateKeyToAccount(process.env.PRIVATE_KEY1 as `0x${string}`);
const ownerPublicAddress = signer.address;

const smartAccount = SafeAccount.initializeNewAccount([ownerPublicAddress]);

let userOperation = ... // smartAccount.createUserOperation(..)

const chainId = BigInt(process.env.CHAIN_ID as string);
const safeUserOpHash = SafeAccount.getUserOperationEip712Hash(
  userOperation,
  chainId
) as `0x${string}`;

const signature = await signer.sign({ hash: safeUserOpHash });

const formatedSig = SafeAccount.formatEip712SignaturesToUseroperationSignature(
  [ownerPublicAddress],
  [signature],
  { isMultiChainSignature: true }, // required for SafeMultiChainSigAccountV1 and V2; omit for SafeAccountV0_3_0 and V0_2_0
);
userOperation.signature = formatedSig;
```
